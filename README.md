# LTP Lighting Ops

Standalone internal estimating and inventory tool for Light The Peak.

## Current modules
- Virtual Christmas quote builder
- 15-inch C9 material calculations
- Bush mini-strand calculations
- Inventory projection
- Purchasing recommendations
- Jobber technician handoff
- Owner / VA interface separation

## Important
Current repository version is the standalone front-end foundation. True multi-user authentication and shared persistent inventory database are the next production layer.
